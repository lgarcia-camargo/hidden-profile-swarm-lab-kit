# Primary Caller app shell

The API-driven UI lives in **`services/primary-caller/web/`**.

After `npm run build` in that folder, open **http://127.0.0.1:8787/app/** with the API running (`services/primary-caller/main.py`).

See [services/primary-caller/README.md](../services/primary-caller/README.md) for the full runbook.
